# EwE School Website

Маркетинговый сайт школы английского языка.

## Стек
- Next.js 14, TypeScript, Tailwind CSS
- i18n (ru/en) через lib/dictionaries
- Sanity CMS
- Framer Motion (анимации)
- React Leaflet (карты)

## Структура
- `app/` — страницы (home, courses, enroll, promo, ambassador, branches)
- `app/api/enroll/` — API формы записи → Telegram бот
- `components/` — UI компоненты
- `lib/` — утилиты, словари i18n (ru.json, en.json)
- `public/` — статика
- `sanity/` — схемы CMS

## Правила
- Все тексты через i18n словари, не хардкодить
- Стили через Tailwind
- Формы отправляют данные в Telegram группу через API

## Команды
- `npm run dev` — dev сервер
- `npm run build` — сборка
- `npm run lint` — проверка ESLint

## Законодательство РФ

Сайт работает на территории РФ — соблюдай требования при разработке.

### 152-ФЗ (персональные данные)
- Все формы лидов (enroll, promo, ambassador) — обязательный чекбокс согласия на обработку ПД со ссылкой на политику конфиденциальности
- Форма не отправляется без отмеченного чекбокса
- Должна быть страница «Политика конфиденциальности»: что собираем, цели, сроки, права субъекта, контакты оператора
- Персональные данные хранятся на серверах в РФ (план миграции с Vercel на Timeweb Cloud)

### 149-ФЗ (информация)
- Реквизиты организации в footer и на «Контактах»
- Пользовательское соглашение по ссылке

### 38-ФЗ (реклама)
- Промо-блоки и акции помечать как реклама, указывать рекламодателя
- Акции — со сроками и условиями

### 2300-1 (защита прав потребителей)
- Полная информация об услугах (курсы, стоимость, условия)
- Публичная оферта по ссылке
- Реквизиты исполнителя: полное наименование, ОГРН/ИНН, юр. адрес

### 436-ФЗ (защита детей)
- Контент с возрастной маркировкой (0+, 6+, 12+, 16+, 18+) — особенно курсы для детей

### Практика
- Footer — ссылки на политику конфиденциальности и пользовательское соглашение
- Страница «Контакты» — полные реквизиты организации
- При создании новой формы — сразу с чекбоксом согласия
